# ELITE 16

Клон Elite (1984) в стиле 16-битной консоли: 320×224, ограниченная палитра,
дизеринг, плоские полигоны. Всё написано с нуля на JavaScript + canvas,
без библиотек и сборки.

## Запуск

```bash
cd ~/Projects/elite16
python3 -m http.server 8080
# открыть http://localhost:8080
```

Можно и просто открыть `index.html` файлом — все скрипты классические, ES-модулей нет.

## Управление

| В полёте | |
|---|---|
| Стрелки / WASD / мышь | тангаж и крен |
| Space или ЛКМ | лазеры |
| X / Z | ускорение / торможение |
| M | пуск ракеты (по ближайшей цели в прицеле) |
| E | E.C.M. (уничтожает ракеты) |
| Tab | энергобомба |
| L | стыковочный компьютер (если куплен) |
| J | прыжок внутри системы (0.1 LY топлива) |
| C | карта галактики (и гиперпрыжок из космоса) |
| V | статус командира |
| Esc | пауза / справка |

В доке: `1`–`6` — рынок, оборудование, карта, статус, старт, сохранение;
`F` — заправка; в рынке `B`/`S` — купить/продать 1 т, `Shift+B`/`Shift+S` — 10 т.

## Что из Elite на месте

- **Полёт**: только тангаж и крен, без рыскания; движение по вектору носа.
- **Стыковка**: вращающаяся станция Кориолиса (кубооктаэдр), щель на грани;
  нужно попасть в створ, совпав с вращением и погасив скорость. Есть
  стыковочный компьютер с автоматическим заходом.
- **Торговля**: 17 товаров, цены зависят от экономики системы, случайный
  разброс при каждом заходе, спрос/предложение, трюм 20 т (35 т с расширением).
- **Галактика**: 8 галактик по 256 систем, названия в стиле Elite, экономика,
  правительство, техуровень, население, радиус, расстояние в световых годах,
  максимальный прыжок 7 LY, топливо 7 LY.
- **Бой**: лазеры (импульсный, лучевой, военный, буровой) с перегревом,
  ракеты с самонаведением, E.C.M., энергобомба, щиты спереди/сзади, энергия,
  четыре банка (полоса EN).
- **Корабли**: Cobra Mk III, Sidewinder, Krait, Mamba, Adder, Python, Viper
  (полиция), Asp, Moray, Fer-de-Lance, Thargoid, Shuttle, астероиды, контейнеры,
  спасательные капсулы, ракеты, станция.
- **Правовой статус**: убийство торговцев и полиции делает вас преступником,
  за пиратов платят награду; статус CLEAN / OFFENDER / FUGITIVE.
- **Ранги**: от HARMLESS до ELITE по числу побед.
- **Оборудование**: ракеты, большой трюм, E.C.M., топливный скoup, лазеры,
  энергобомба, спасательная капсула, доп. энергоустановка, стыковочный
  компьютер, галактический гипердрайв. Доступность зависит от техуровня.
- **Планеты и звезда**: процедурные планеты (5 типов), солнечная корона,
  сгорание в атмосфере, смерть у звезды, заправка топливным скoupом.
- **Смерть и спасение**: капсула спасает, но забирает половину денег и груз.
- **Сохранение** командира в localStorage.

## Чего нет

- Миссий (Constrictor, документы таргоидов) и званий за них.
- Торговли с другими кораблями, захвата груза, «rock hermit».
- Полноценной 3D-модели повреждений и отстрела частей корабля.

## Как сделана графика

- Внутреннее разрешение 320×224 (как у Mega Drive), апскейл целым
  коэффициентом, `image-rendering: pixelated`.
- Палитра: 12 рампов по 6 оттенков (72 цвета) + упорядоченный дизеринг
  Байера 4×4 — им сглаживаются и заливка граней, и градиент фона, и планеты.
- Корабли — низкополигональные меши (лофтинг эллиптических сечений + призмы),
  плоская заливка по нормали к фиксированному источнику света, отсечение
  задних граней, сортировка по глубине, клиппинг по ближней плоскости.
- Планеты пререндерятся в спрайты: один раз строится текстура в
  долгота/широта, потом 8 кадров вращения с термінатором.
- Шрифт — собственный битмап 5×7, свой растеризатор полигонов и линий.

## Файлы

```
index.html        страница и обвязка
js/render.js      палитра, фреймбуфер, растеризатор, шрифт, 3D-камера
js/models.js      меши кораблей, станция, астероиды, планеты
js/galaxy.js      генерация галактик, рынок, оборудование, ранги
js/game.js        полёт, бой, стыковка, гиперпрыжок, ИИ, экономика
js/ui.js          дашборд, сканер, экраны станции
js/main.js        ввод, игровой цикл, звук (WebAudio)
tools/            headless-тесты и рендер контактных листов
```
