# Helios Drift

Космический торговый симулятор с пиксельной графикой и двумя режимами: **Classic** — правила 1984 года (две миссии, никаких
контрактов и верфи), **Advanced** — всё, что добавлено сверху: кампания из
восьми этапов, доска контрактов, верфь, шахты.

Название и все имена собственные в игре — свои. Слово Elite не используется:
это зарегистрированный товарный знак Frontier Developments, и эта игра не
связана с ним. Чужие имена из игры-вдохновителя тоже заменены: верхний ранг
называется **LEGEND** («Легенда»), флагман верфи — **KESTREL III**
(«Кестрель III»), прототип из сюжетной миссии — **SHRIKE** («Шрайк»),
враждебная раса — **SWARM** («Рой»). Внутренние идентификаторы в коде
(ship keys вроде `cobra3`) остались прежними — они не показываются игроку и
не ломают старые сохранения.

Внутри две реализации одного движка:

```
HeliosDrift.app  готовое приложение — двойной клик
run.command      собрать (если нужно) и запустить
go/              исходники: Go + Ebiten
js-reference/    та же игра на JavaScript/canvas (эталон, идёт в браузере)
```

## Играть

Двойной клик по **`HeliosDrift.app`**. Или:

```bash
open HeliosDrift.app
```

`run.command` делает то же самое, но перед запуском пересобирает бинарь,
если исходники новее.

**Важно:** запускать `go/elite16` напрямую нельзя — macOS роняет голый
бинаррь, который пытается открыть окно (`NSRemoteView encountered app
without bundle`). Приложение должно жить внутри `.app`; игра теперь сама
скажет об этом, если её запустить не оттуда.

Без окна бинарь работает как раньше: `./go/heliosdrift -sim`, `-shots`.

Файлы настроек и сохранений остались с прежними именами (`~/.elite16-*`) —
так старые сохранения не теряются при смене названия.

## Управление

| В полёте | |
|---|---|
| Стрелки / WASD / мышь | тангаж и крен |
| Space / ЛКМ | лазеры |
| X / Z | ускорение / торможение |
| M | ракета |
| E | E.C.M. |
| Tab | энергобомба |
| L | стыковочный компьютер |
| J | прыжок внутри системы |
| G | галактический гипердрайв (следующая галактика) |
| K | сбросить 1 т груза за борт |
| Геймпад | стик — крен/тангаж, курки — скорость, A — огонь, B — ракета, X — ECM, Y — стыковка |
| C | карта галактики (H — прыжок) |
| V | статус командира |
| Esc | пауза |
| F10 (настраивается) | звук вкл/выкл |

В доке: `1` рынок, `2` оборудование, `3` верфь, `4` карта, `5` статус,
`6` старт, `7` сохранение (3 слота), `8` настройки, `9` задание,
`0` доска контрактов, `F` заправка. На рынке `B`/`S` — купить/продать
1 т, `Shift+B`/`Shift+S` — 10 т.

## Переназначение управления

`Esc` → настройки (или пункт `8` в доке) → **УПРАВЛЕНИЕ**. В списке все
действия: тангаж, крен, огонь, скорость, ракета, ECM, бомба, стыковочный
компьютер, прыжки, карта, статус, пауза, звук.

- ↑/↓ — выбрать действие;
- `Enter` — назначить **основную** клавишу (после нажатия жми клавишу или
  кнопку геймпада);
- `Shift+Enter` — назначить **вторую** клавишу: на действие можно повесить
  две, как в заводской раскладке `LEFT/A`;
- `Backspace` — вернуть выбранной строке заводскую привязку (весь список
  сбрасывается пунктом внизу);
- `Esc` — отменить захват;
- пункт **СБРОС ПО УМОЛЧАНИЮ** внизу списка возвращает заводскую раскладку.

Назначенная клавиша **забирается** у того действия, где она была раньше.
Иначе получалось, что новую привязку сделать вроде можно, но старое действие
продолжает срабатывать на той же клавише — и, например, `W` одновременно
давала газ и тангаж. Теперь привязка одна: поставил `W` на газ — тангаж вверх
её больше не получит, а останется на стрелке.

Текущая привязка видна в колонке `KEY` как `LEFT/A`: слева основная, справа
вторая. Пока идёт захват, в этой же колонке показывается клавиша, которую
видит игра, — так сразу понятно, дошло ли нажатие.

Привязки хранятся в `~/.heliosdrift-keys.json` и подхватываются при запуске.
Стики геймпада (крен/тангаж, куртки на скорость) остаются аналоговыми и не
переназначаются. Клавиши меню (стрелки, Enter, цифры) фиксированы — иначе
из настроек было бы не выбраться.

## Язык и настройки

Экран настроек: с титульного экрана (пункт `3`) или из дока (`7`).
Стрелки ↑/↓ — выбор строки, ←/→ или Enter — изменение, Esc — выход.

- **ЯЗЫК** — английский / русский, переключается на месте;
- **ЗВУК** — вкл/выкл (в полёте дублируется клавишей `F10`, она же
  переназначается в управлении как `SOUND`);
- **ГРОМКОСТЬ** — 5 ступеней.

Выбор сохраняется в `~/.elite16-config.json` и подхватывается при запуске.

## Проверка без окна

```bash
cd go
./heliosdrift -sim      # прогон: стыковка, гиперпрыжок, бой, сейв/лоад
./heliosdrift -shots    # эталонные экраны в go/build/*.png
go test ./sfx       # проверка синтеза звука
```

Подробности — в `go/README.md`.

## Сохранение

Три слота: `7` в доке — запись (экран со списком слотов), `2` на титульном
экране — загрузка. Файлы лежат в `~/.elite16-save1.json` … `-save3.json`;
старый одиночный `~/.elite16-save.json` подхватывается как первый слот.
Слот показывает имя пилота, деньги и систему, где он стоит.

## Что внутри

**20 летающих корпусов** — весь список 1984 года: Adder, Anaconda, Asp Mk II,
Boa, Kestrel I, Kestrel III, Shrike, Fer-de-Lance, Gecko, Krait, Mamba,
Moray Starboat, Python, Shuttle, Sidewinder, Swarm, дрон роя,
Transporter, Viper, Worm. Плюс объекты: астероид, контейнер, спасательная
капсула, ракета, станция.

**Три типа станций**: Coriolis (кубооктаэдр, стартовая), додекаэдр (каждая
четвёртая система, со шпилями и окнами) и рок-эрмит (редкий, примерно семь на
галактику, с выступающим стыковочным воротом и наценкой 35%).

**17 товаров** — полный список: Food, Textiles, Radioactives, Slaves,
Liquor/Wines, Luxuries, Narcotics, Computers, Machinery, Alloys, Firearms,
Furs, Minerals, Gold, Platinum, Gem-Stones, Alien Items.

**Оружие и оснастка**: 4 лазера (импульсный, лучевой, военный, шахтёрский),
ракеты с самонаведением, E.C.M., энергобомба, топливный ковш, большой трюм,
дополнительный энергоблок, стыковочный компьютер, спасательная капсула,
галактический гипердрайв (одноразовый, как в оригинале).

**Кампания (Advanced, 8 этапов)**: «МЕДИЦИНСКИЙ РЕЙС» → «ЗАСАДА» → «ЧЁРНЫЙ
ЯЩИК» → «КУРЬЕР» → «КАРАВАН» → «ПОДСТАВА» → «УЛЕЙ» → «ФЛАГМАН». Линия про
независимого пилота, комбинат «Хелиос», проданные координаты прыжков и
артефакт, который оказался сигналом. Этапы используют только те механики,
что есть в игре: доставка груза, зачистка контактов в системе, убийство
конкретной цели, маткорабель роя. Прогресс виден в журнале.

Сценарий кампании написан отдельно, как повесть: **[docs/campaign.md](docs/campaign.md)** —
восемь глав по восьми этапам, с дословными репликами брифингов.

**Два сюжетных задания (Classic)**:
1. *Shrike* («Шрайк») — с ранга AVERAGE военное командование просит найти и
   уничтожить прототип. Цель — конкретная система в радиусе 7 св. лет,
   награда 5000 CR.
2. *Swarm documents* — после первого задания: доставить документы в штаб
   в следующей галактике. Нужен галактический гипердрайв; в пути — засада
   роя. Награда 15 000 CR.
3. *Swarm mothership* — только в Advanced, после первых двух: уничтожить
   маткорабель роя, охраняемый четырьмя дронами. Награда 25 000 CR.

**Журнал** (`ЖУРНАЛ` в доке): сюжетный контракт с оплатой и все принятые
задания с прогрессом — сколько пиратов из скольких уже убито, сколько дней до
срока осталось.

**Метки заданий**: на галактической карте цель сюжетного контракта отмечается
пульсирующей рамкой, цели принятых контрактов — зелёными точками. Так работа
видна, даже если забыл, куда лететь.

**9 рангов**: Harmless → Mostly Harmless → Poor → Average → Above Average →
Competent → Dangerous → Deadly → Elite.

**8 галактик × 256 систем**, 5 типов планет, генерируемые рынки, войны
экономик, полиция и розыск.

## Проходимость

У Elite нет финала — это песочница. «Пройти» её можно двумя способами:
выполнить оба контракта и дойти до ранга **ELITE** (6400 убийств). После
второго задания счётчик целей не обнуляется, игра продолжается бесконечно.

## Два режима: Classic и Advanced

Режим выбирается **один раз при создании пилота** (титульный экран → НОВАЯ ИГРА →
КЛАССИКА / РАСШИРЕННЫЙ) и сохраняется вместе с ним. Сменить его нельзя — ни в
настройках, ни в доке.

| | Classic | Advanced |
|---|---|---|
| Сюжетные миссии (Шрайк, документы) | да | да |
| Доска контрактов (курьер, пассажиры, почта, заказ) | нет | да |
| Верфь и смена корабля | нет, только Cobra Mk III | 5 корпусов |
| Сброс груза (`K`) | нет | да |
| Прыжок внутри системы (`J`) | нет | да |
| Всё остальное (полёт, бой, торговля, шахты, гиперпрыжки, 8 галактик, ранги) | да | да |

Клавиши, переназначение управления, слоты сохранения и язык — это интерфейс, они
одинаковы в обоих режимах.

## Дополнено после первого релиза

- **Температура кабины (CT)** — прибор на панели; у звезды кабина греется,
  выше 80% идёт урон, на 100% — смерть. Вдали от звезды остывает.
- **Ведьминское пространство** — сбой гиперпрыжка выбрасывает в пустоту без
  планеты и станции, с кораблями роя; выйти можно только прыжком.
- **Трафик из станции** — корабли вылетают из щели и уходят, а не появляются
  из ниоткуда.
- **Обломки** — астероид → 3 обломка → осколки; осколки бывают минеральные,
  золотые, платиновые, с камнями. Плюс пластины обшивки с погибших кораблей.
- **Рок-эрмит** — станция-астероид примерно в семи системах на галактику, цены выше
  на 35%.
- **Корабль поколений** — редкий гигант в каждой тринадцатой системе.
- **Контракты** — теперь с дедлайнами (дни), четыре типа: курьер, пассажиры,
  почта, заказ на пиратов. Просрочка — штраф.
- **Верфь** — 5 корпусов (Cobra Mk III, Adder, Python, Fer-de-Lance, Asp),
  зачёт старого корабля 60%.
- **Три слота сохранения** — с именем, деньгами и системой.
- **Сброс груза** — `K` выбрасывает тонну в контейнере.
- **Геймпад** — стик и кнопки, см. таблицу управления.

## Сборки

`./build.sh` собирает всё разом — кросс-компиляция без cgo, нужен только Go:

| файл | для кого |
|---|---|
| `dist/HeliosDrift-linux-x86_64.tar.gz` | Steam Deck, SteamOS, любой дистрибутив с glibc |
| `dist/HeliosDrift-linux-arm64` | Linux на ARM |
| `dist/HeliosDrift-windows-x86_64.zip` | Windows 10/11 |
| `dist/HeliosDrift-macos-arm64.zip` | macOS на Apple Silicon — распаковать и запустить `HeliosDrift.app` |
| `dist/heliosdrift-darwin-arm64` | голый бинарник macOS (только для `-sim` и отладки) |

Версия вшивается при сборке (`git describe` или имя тега) и видна в углу
титульного экрана, а также печатается по `-version`. На macOS игра идёт
только из бандла `HeliosDrift.app`: голый Mach-O не может открыть окно, и
двойной клик по нему открывает терминал с сообщением.

Бинарники самодостаточные: ассетов рядом не нужно, все модели и звуки
генерируются при старте. Сохранения и настройки — в домашнем каталоге,
`.heliosdrift-*`, рядом с бинарником ничего не пишется.

На Linux игра сначала проверяет, есть ли звуковой сервер (PulseAudio,
PipeWire или ALSA-устройство). Если нет — запускается молча, а не падает:
Ebiten считает отсутствие аудио фатальной ошибкой. Принудительно отключить
звук можно переменной `HELIOS_NO_AUDIO=1`.

## Steam Deck

1. В Desktop Mode скопировать `HeliosDrift-linux-x86_64.tar.gz` на Deck,
   распаковать, например в `~/Games/heliosdrift`.
2. Steam → «Добавить игру» → «Добавить стороннюю игру» → выбрать файл
   `heliosdrift`.
3. Запускать из Game Mode. **Proton включать не нужно** — это нативная
   Linux-сборка, с Proton она не запустится.
4. Управление: стики — тангаж и крен, триггеры — тяга и торможение,
   `A` — выбор в меню, `B` — назад, D-pad — навигация по спискам.
   `F11` — полный экран (окно 960×672 на экране 1280×800).

Сохранения на Deck лежат в `/home/deck/.heliosdrift-save1.json` и т.д.
