# Helios Drift

Космический торговый симулятор с пиксельной графикой: восемь галактик,
торговля, пираты, стыковки и два режима.

**Classic** — правила 1984 года, вдохновлённые игрой Elite: две сюжетные
миссии, один корабль, никаких контрактов и верфи.
**Advanced** — всё, что добавлено сверху: кампания из восьми этапов, доска
контрактов, верфь, шахты, рысканье.

Имена собственные в игре свои: верхний ранг — **LEGEND**, флагман верфи —
**KESTREL III**, прототип из сюжета — **SHRIKE**, враждебная раса — **SWARM**.

## Скачать

Готовые сборки: **[последний релиз](https://github.com/DruzhininPavel/helios-drift/releases/latest)**

| платформа | файл | как запускать |
|---|---|---|
| macOS, Apple Silicon | `HeliosDrift-macos-arm64.zip` | распаковать, запустить `HeliosDrift.app` |
| Windows 10/11 | `HeliosDrift-windows-x86_64.zip` | распаковать, запустить `heliosdrift.exe` |
| Linux, Steam Deck | `HeliosDrift-linux-x86_64.tar.gz` | `tar xzf … && ./heliosdrift` |
| Linux на ARM | `heliosdrift-linux-arm64` | `chmod +x` и запустить |

`heliosdrift-console.exe` в архиве для Windows — та же игра, но с консольным
окном: туда печатаются сообщения при отладке.

**Steam Deck.** Распаковать архив в `~/Games/heliosdrift`, в Desktop Mode
добавить в Steam как стороннюю игру, запускать из Game Mode. Proton не нужен:
это нативная Linux-сборка. `F11` — полный экран.

## Управление

| В полёте | |
|---|---|
| Стрелки / WASD / мышь | тангаж и крен |
| Q / R | рысканье (только Advanced) |
| Space / ЛКМ | лазеры |
| X / Z | ускорение / торможение |
| M | ракета |
| E | E.C.M. |
| Tab | энергобомба |
| L | стыковочный компьютер |
| J | прыжок внутри системы |
| G | галактический гипердрайв |
| K | сбросить тонну груза |
| C | карта галактики (H — прыжок) |
| V | статус командира |
| Esc | пауза |
| F10 | звук вкл/выкл |
| Q в паузе | выход в главное меню |

В доке список услуг: рынок, оборудование, верфь (только Advanced), карта,
статус, старт, сохранение, настройки, задание, контракты, журнал. Цифра —
номер строки, стрелки — выбор, `Enter` — вход, `F` — заправка. На рынке
`B`/`S` — купить/продать тонну, с `Shift` — десять.

Геймпад работает по стандартной раскладке: стик — тангаж и крен, курки —
тяга, `A` — огонь, `B` — ракета, `X` — ECM, `Y` — стыковка, D-pad — навигация
по меню. Всё переназначается.

## Настройки

`Esc` в полёте или `8` в доке — настройки: язык (английский / русский), звук,
громкость. Там же **УПРАВЛЕНИЕ**: у каждого действия своя клавиша, вторая
кладётся `Shift+Enter`, `Backspace` сбрасывает строку. Назначенная клавиша
забирается у прежнего действия, поэтому `W` не может одновременно давать газ
и тангаж. Последняя строка — **ТЕСТ ГЕЙМПАДА**: экран показывает, что игра
реально получает от устройства.

## Два режима

Режим выбирается один раз при создании пилота и сохраняется вместе с ним.

| | Classic | Advanced |
|---|---|---|
| Сюжетные миссии | две, 1984 года | кампания из 8 этапов |
| Контракты, верфь, шахты | нет | да |
| Корабли | один | пять |
| Рысканье, прыжок в системе, сброс груза | нет | да |
| Полёт, бой, торговля, гиперпрыжки, 8 галактик, ранги | да | да |

Девять рангов, от Harmless до **Legend**. В Classic «пройти» игру — значит
выполнить обе миссии и дойти до верхнего ранга; в Advanced — закрыть
кампанию: восемь этапов про независимого пилота, комбинат «Хелиос» и
артефакт, который оказался сигналом. Сценарий целиком, как повесть, —
в [docs/campaign.md](docs/campaign.md).

## Сохранения и сид

Три слота: `7` в доке — запись, второй пункт титульного экрана — загрузка.
Файлы: `~/.heliosdrift-save1.json` и далее; настройки и привязки клавиш лежат
рядом, `~/.heliosdrift-config.json` и `~/.heliosdrift-keys.json`.

Каждый запуск получает свой мир: сид выбирается случайно и напечатан в углу
титульного экрана (`SEED 48213907`). Тот же мир повторяется флагом `-seed`:

```bash
./heliosdrift -seed 48213907
```

## Развитие

Кампания проходится и на стартовом корабле, но к финалу это долго: флагману
нужно 176 попаданий из импульсного лазера против 61 из военного. Деньги
приходят с этапов кампании и с доски контрактов — курьер, пассажиры, почта,
заказ на пиратов, контрабанда. Тратить их есть на что: четыре лазера, два
усилителя щитов, второй грузовой отсек, тяжёлая буровая установка и пять
корпусов с разной манёвренностью.

Подробно — [docs/progression.md](docs/progression.md).

## Что внутри

20 летающих корпусов, три типа станций (Coriolis, додекаэдр, рок-эрмит),
17 товаров, четыре лазера, ракеты, ECM, бомба, топливный ковш, большой трюм,
стыковочный компьютер, спасательная капсула, галактический гипердрайв.

Восемь галактик по 256 систем, генерируемые рынки, полиция и розыск,
контракты с дедлайнами, верфь с зачётом старого корабля, шахты и обломки,
корабль поколений, температура кабины, ведьминское пространство при сбое
гиперпрыжка.

## Собрать самому

Нужен только Go: `./build.sh` собирает все платформы в `dist/`. Приложение
для macOS (`HeliosDrift.app`) и скрипт `run.command` — для локального запуска
на Mac.

Без окна игра умеет прогонять себя: `./heliosdrift -sim` (стыковка,
гиперпрыжок, бой, сохранение), `-shots` (эталонные экраны), `-version`.

В бинарнике есть бот-игрок: он сам летает, торгует, воюет и проходит кампанию
без окна, проверяя игру на невозможные состояния. Подробности —
в [docs/bot-testing.md](docs/bot-testing.md).
