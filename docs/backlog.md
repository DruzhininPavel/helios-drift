## Кокпит

**1. Разные кокпиты у разных кораблей.**
Сейчас `cockpit()` в `go/ui/ui.go` рисует одну и ту же раму для всех: стальные
балки по краям, остекление, нижняя панель. Хочется, чтобы кабина читалась как
часть корпуса:

| корпус | какой кокпит |
|---|---|
| Kestrel III | нынешний, всесторонний обзор, широкая рама |
| Adder | тесный, узкие стёкла, много переборок: дешёвый корабль |
| Python | панорамный «грузовик»: широкая нижняя панель, обзор вперёд и вниз |
| Asp Mk II | военный: узкие бойницы, приборная стойка по центру |
| Fer-de-Lance | низкая посадка, обзор «в щель», агрессивные углы |

Как делать: таблица профилей по `Cmd.Ship` — набор полигонов рамы, цвет
остекления, положение нижней панели. Всё в одном месте, `cockpit(fb)` выбирает
профиль по кораблю. Механика не меняется, только отрисовка.

**2. Решить, что делать с отключённым кокпитом.**
Вопрос открыт. Варианты:

- оставить как есть — рама есть всегда;
- настройка «КОКПИТ: ВКЛ / ВЫКЛ» — без рамы экран чистый, только HUD;
- убрать раму совсем и оставить только HUD.

Нужно выбрать, прежде чем делать разные кабины: если кокпит можно будет
отключить, профили должны рисоваться отдельно от HUD, чтобы выключение ничего
не ломало.

## Известные ограничения

- Бот проходит кампанию и зарабатывает, но ручная стыковка без компьютера у
  него пока не получается стабильно (`-manual-dock`).
- Кампания укладывается в 5–7 минут игры для бота; человеку — дольше, но всё
  равно коротко для восьми глав.
