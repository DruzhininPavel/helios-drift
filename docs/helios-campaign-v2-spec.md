# Helios Drift: кампания Advanced v2 — спецификация внедрения

Документ написан как промт для разработчика (или ИИ-ассистента в репозитории). Источник текстов — `helios-campaign-v2-story.md`: каждая реплика, которую видит игрок, помечена там комментарием `<!-- node: ID -->`, ID совпадают с таблицами ниже. Тексты не дублируются здесь, чтобы не расходились.

## 0. Задача и рамки

**Сделать:** заменить кампанию из восьми «прилети и убей» этапов на восемь глав со сделками, выбором и последствиями; добавить экран диалога, метки в сейве, предмет «ЯЩИК», три концовки.

**Не трогать:** Classic (там нет кампании), полёт, бой, торговлю, ранги, форматы сейвов вне нужных полей. Новые рисунки не нужны, нужна одна новая цифра в HUD (счётчик зрителей, глава 4).

**Читать перед работой:** `README.md`, `go/game/campaign.go` (срез `campaignQuests`), `go/lang/ru.go`, `TestCampaignChain` в `go/game/mode_test.go`.

**Жёсткие ограничения текста:** экран 320×224, шрифт 5×7 с шагом 6 px, видимое окно текста — 6 строк по 46 знаков, узел — до 30 строк (≈1 300 знаков). Весь игровой текст капслоком. Строки — ключи латиницей, перевод в `go/lang/ru.go`; каждая реплика — две строки в двух файлах.

**Правила голоса (проверять при вводе текстов):**
1. Контора («КОМБИНАТ», «УЛЕЙ») не врёт: каждая её фраза буквально верна.
2. Пилот не говорит: у него только варианты ответа.
3. «Ты» → «вы»: контора говорит «ты» до узла `c6_hive3`, с него и дальше — «вы». В английском — аналогичный сдвиг, если язык допускает.

## 1. Модель данных

```go
type Node struct {
    ID      string
    Kind    string    // "talk" | "msg" | "screen"
    Speaker string    // "" для системных сообщений
    Lines   []string  // ключи строк; перенос по словам делает движок
    Options []Option  // для "talk"; "msg" и "screen" без вариантов
    OnEnter []Effect  // сработает при открытии узла
}

type Option struct {
    Text string   // ключ строки
    Next string   // следующий узел; "" — конец диалога
    If   []Cond   // вариант виден, только если все условия верны
    Do   []Effect
}

type Cond   struct { Key string; Op string; N int }   // flag, !flag, ==, >=, <=
type Effect struct { Kind string; Key string; N int; S string }
```

**Виды эффектов (`Effect.Kind`):**

| Kind | Что делает |
|---|---|
| `flag`, `unflag` | поставить / снять метку |
| `cash` | ± кредиты (N) |
| `papers` | +N к счётчику «подписанных бумаг» |
| `box` | ±N ящиков в трюме |
| `rep` | репутация (Key — фракция, N — сдвиг) |
| `wanted` | розыск ±N |
| `spawn` | выпустить группу кораблей (Key — группа, S — метка цели) |
| `price` | временный модификатор цен (Key — система или `*`, N — процент, S — часы игрового времени) |
| `clock` | запустить/сдвинуть таймер «Вайперов» |
| `audit` | выставить результат седьмой главы: `broken` / `runs` / `rewritten` |
| `bounty` | заказ на пилота на доске найма (N — сумма) |
| `quest` | перейти к следующему этапу |

**Состояние в сейве (`Cmd`):**

```go
Flags    map[string]bool
Papers   int      // «подписанных бумаг»
Boxes    int      // ящиков в трюме
Audit    string   // "", "broken", "runs", "rewritten"
Ending   string   // "", "combine", "chaos", "council"
ViperClk int      // прыжков до «Вайперов»; -1 — таймер не идёт
```

Все новые поля — с безопасными значениями по умолчанию, чтобы старые сейвы читались. Classic их игнорирует.

## 2. Экран диалога (`TALK`)

- Вход: пункт меню станции `TALK`, виден, только если в системе есть контакт текущей главы. Узлы вида `msg` (брифинги, системные сообщения) показываются без входа: приходят в терминал и на доску.
- Окно текста: 6 видимых строк по 46 знаков. `↑`/`↓` — строка, `PgUp`/`PgDn` — страница, справа индикатор `3/7`. Варианты закреплены внизу, не прокручиваются.
- Вид `screen`: журнал-экран без вариантов и без кнопок. Нужен для `СТАНЦИИ ПОД ЗАКРЫТИЕ` (глава 4) — навсегда остаётся в журнале и **не предлагает действий**, это намеренно.
- Подстановки: `{N}` — число подписанных бумаг (`Papers`).
- Условный текст: узлы с суффиксом `A`/`B` выбираются по условию (см. главы).

## 3. Предмет «ЯЩИК»

| Свойство | Правило |
|---|---|
| Трюм | занимает 2 т; в списке трюма колонка называется **НОМИНАЛ**, а не ЦЕНА; значение 40 000 |
| Рынок | продать нельзя: ответ `ВЛАДЕЛЕЦ — ДЕРЖАТЕЛЬ` |
| Сброс | клавиша `K` отвечает `ГРУЗ ПРИВЯЗАН К ПИЛОТУ`, тонна не уходит |
| Кабина | гудение звуком; температура кабины растёт на небольшую величину за каждый ящик и за каждые сутки (использовать существующую модель температуры) |
| Верфь | при смене корабля ящики переезжают вместе с пилотом; 2 т на новом корабле резервируются |
| Гибель, капсула | ящик остаётся в обломках; подобрать его снова можно (ковшом); счётчик `Boxes` отражает реальное число |
| Ковш | поднимает ящик, как любой груз. В главе 5 это ловушка: ещё один ящик и ещё одна бумага |
| Выброс при финале | см. раздел 6 |

## 4. Метки и счётчики

**Обладание** (что у пилота): `Boxes`, `HAS_RECEIPT`, `HAS_LIST`, `HAS_COPY`, `BOUGHT_LICENSE`.
**Знание** (что он выяснил): `KNOWS_BOX`, `KNOWS_HIVE`, `ASKED_PRICE`, `COPIED_RECORDER`, `READ_LIST`.
**Судьба** (что стало с людьми): `COURIER_ALIVE`, `COURIER_DEAD`, `DISP_OUT` (клиника закрыта, диспетчера нет), `KILLED_COLLECTORS`, `SPARED_CMD`, `PAID_PERMIT`, `PAID_CLINIC`.
**Ход глав:** `REFUSED_SEAL`, `CONVOY_BROKEN`, `CONVOY_PASSED`, `GREED` (поднял ящик в главе 5), `EXT1`, `EXT2` (выписки из архивов 1 и 2), `CLERK1_ANGRY`, `FORGED`, `MET_AUDITOR`.

**Счётчик бумаг (`Papers`).** Каждый узел, помеченный «бумага» в таблице ниже, увеличивает его на 1. Старт: 0. Это не метка, а число: в главе 8 оно определяет, можно ли взять печать без боя (порог **5**).

### Глава 1. Ящик

Цель: система клиники «Тихая Гавань» (3 прыжка от старта). Метка квеста `CLINIC`.

| Узел | Условие | Варианты и эффекты |

Во всех ветках: `cash +1200` за приёмку (контора платит ровно столько, сколько обещала). Награда не зависит от выбора, расписка не даёт денег.

### Глава 2. Три корабля

Запускается личным сообщением в терминал через сутки после приёмки. Три «Крайта» (метка `AMBUSH`).

| Узел | Условие | Содержание |
|---|---|---|
| `c2_briefA` | `Boxes >= 1` | брифинг, ветка A: засада на выходе из системы |
| `c2_briefB` | `REFUSED_SEAL` | брифинг, ветка B: засада у клиники |
| `c2_cmdA` + `c2_cmdA_custodian` | ветка A | диалог до боя. Вторая реплика добавляется при `HAS_RECEIPT` |
| `c2_cmdB` | ветка B | диалог до боя |
| `c2_paid` | оплатил | ответ командира |
| `c2_spared` | корпус командира ниже 25% | командир выходит на связь и сдаётся; игрок может перестать стрелять |
| `c2_jump` | ушёл в прыжок | сообщение о штрафе и поручителе |

**Варианты (одинаковые по форме в обеих ветках):**

| Вариант | Условие показа | Эффекты |
|---|---|---|
| ОПЛАТИТЬ ДОПУСК | `cash >= цена` (A: 3 000, при `HAS_RECEIPT` 4 500; B: 3 000) | `cash −цена`, `papers +1`, `flag PAID_PERMIT` (A) или `PAID_CLINIC` (B), `rep` местной артели +1 |
| ДРАТЬСЯ | всегда | бой с группой `AMBUSH`; награда 2 600 по завершении; `rep` правительства −1 при убийстве всех; в ветке B клиника защищена |
| УЙТИ В ПРЫЖОК | всегда | прыжок считается 4 секунды под огнём; награды нет; ветка A: `flag DISP_OUT`, штраф 40 000 на поручителя (диспетчер); ветка B: то же |

**Пощада:** если игрок прекратил огонь, когда `c2_spared` показан, выставить `flag SPARED_CMD`, корабль командира уходит. Если убит — `flag KILLED_COLLECTORS`.

### Глава 3. Меню

Цель: «Питон»-обломок (метка `HULK`) в соседней системе. Внутри: пустые стеллажи на сорок ящиков, самописец (пищит каждые 8 секунд), доска со списком отработки.

| Узел | Описание |
|---|---|
| `c3_brief` | брифинг в терминал |
| `c3_roster` | `screen` на переборке. Три варианта текста по условию: `PAID_PERMIT` / `Boxes >= 1` без оплаты / `REFUSED_SEAL`; при `KILLED_COLLECTORS` строки «ПОД ОТРАБОТКУ: 0, ВАКАНСИЙ: 3» |
| `c3_recorder` | запись самописца, `screen` |
| `c3_manifest` | приложение, `screen`, три строки таблицы |
| `c3_holo` | голограмма на выходе, один вопрос |

**Самописец.** Кнопка интерфейса `КОПИРОВАТЬ` рядом с самописцем: `flag COPIED_RECORDER`, фрагмент уходит в журнал. Если игрок уничтожает самописец, не нажав кнопку, при следующем брифинге приходит `c3_praise` («ИСПОЛНЕНО КОРРЕКТНО. ЭТО РЕДКОСТЬ»), `papers +1`. Награда за главу: `cash +3 400` в обоих случаях.

**Голограмма (`c3_holo`):**

| Вопрос | Ответ | Эффект и вес |
|---|---|---|
| ЧТО В ЯЩИКЕ | `ОБЯЗАТЕЛЬСТВО СТАНЦИИ. ПЕРЕУСТУПЛЕНО ДЕРЖАТЕЛЮ.` (при `Boxes == 0`: `ПОКА НЕ ПЕРЕУСТУПЛЕНО.`) | `flag KNOWS_BOX`: в главе 6 открывает бесплатный вариант в первом архиве |
| ЧТО ТАКОЕ УЛЕЙ | `ПУНКТ ПРИЁМА. СТАТУС: СЕКРЕТНО.` | `flag KNOWS_HIVE`: в главе 7 монолог без одного абзаца (см. ниже) |
| СКОЛЬКО МНЕ ЗАПЛАТЯТ | `СУММА УКАЗАНА В ДОГОВОРЕ. ДОГОВОР ТЫ ПОДПИСАЛ.` | `flag ASKED_PRICE`: в главе 4 покупка списка стоит 5 500 вместо 7 000 |

**Население.** Если в игре на экране системы показывается население, для трёх станций из манифеста его значение должно совпасть с колонкой «ПОРЦИИ» (40 000 / 120 000 / 8 400). Если не показывается — не добавлять экран ради этого, достаточно совпадения цифры в манифесте и в НОМИНАЛЕ ящика.

### Глава 6. Бумаги

Таймер «Вайперов»: `clock` при старте главы:
- `CONVOY_BROKEN` → `ViperClk = 4` (прыжков до «Вайперов»);
- `CONVOY_PASSED` → `ViperClk = −1` (таймер выключен);
- любая из веток: `FORGED` или `CLERK1_ANGRY` ставят `ViperClk = 1`.

При нуле следующая система встречает двумя «Вайперами» (метка `NAVY`), реплика «СДАЙТЕСЬ. ПОВТОРЯТЬ НЕ БУДУ.» Игрок может сдаться (розыск обнуляется, штраф, глава продолжается), драться или уйти в прыжок (они преследуют до следующей системы).

| ВЫКЛЮЧИТЬ ЩИТЫ СТАНЦИИ | всегда | щиты станции выключаются; матка уязвима; приходят 4 пирата; при `SPARED_CMD` командир среди них и не стреляет; убийство матки: `audit broken`, `cash +25 000` |
| НЕ ВЫКЛЮЧАТЬ | всегда | через 10 минут игрового времени Улей открывает выход; `audit runs`; награды нет |
| ОТКРЫТЬ КАНАЛ | `MET_AUDITOR` и (`EXT1` + `EXT2` + `COPIED_RECORDER` ≥ 2); `FORGED` не считается | предъявить выписки; матка выключается; `audit rewritten`, `cash +25 000` |

**Состояния мира после главы 7** (действуют до конца главы 8):

| `Audit` | Эффект |
|---|---|
| `broken` | цены на всё −30%, контракты на доставку исчезают с доски |
| `runs` | 6 из 18 станций закрыты на пересчёт (нельзя стыковаться), контракты в них снимаются |
| `rewritten` | без изменений, лицензионные сборы отменены |

### Глава 8. Директор

«Анаконда» (метка `FLAGSHIP`): 1 400 прочности, 180 щита, два эскорта.

| Узел | Описание |
|---|---|
| `c8_brief` | брифинг |
| `c8_director` | диалог с Директором. `{N}` — `Papers`; при `Papers < 5` — альтернативный абзац «ЭТО ЧЕСТНО. ЭТО МАЛО» |
| `c8_fin_*` | финальные экраны |

**Варианты и ветвление:**

| Вариант | Условие | Результат |
|---|---|---|
| ВЗЯТЬ ПЕЧАТЬ | всегда | `Papers >= 5` и нет `FORGED`: мирно → `combine`. Иначе бой с «Анакондой» и эскортами; после победы → `combine` (с припиской «БЕЗ ПОДПИСИ») |
| ДАТЬ УЙТИ | всегда | боя нет → `chaos` |
| ПЕРЕДАТЬ ПЕЧАТЬ СТАНЦИЯМ | `COURIER_ALIVE` | `Audit == rewritten` и нет `FORGED`: мирно → `council`. Иначе бой, затем → `council` |

В бою после победы выбор между `combine` и `council` показывается только тем, кто выполнил условия `council`. Максимум три варианта на экране: если `ВЗЯТЬ ПЕЧАТЬ` и `ПЕРЕДАТЬ ПЕЧАТЬ` вместе с `ДАТЬ УЙТИ` не помещаются, приоритет у первого и третьего.

**Награды:** победа над флагманом: `cash +50 000`. После любой концовки: `wanted = 0`, `Ending` выставлен, девятый этап не предлагается.

## 6. Концовки и режим свободной игры

Концовка — это набор правил для свободной игры после титров.

| Концовка | Правила мира | Ящик и `K` |
|---|---|---|
| `combine` | лицензионный сбор 5% с каждой сделки; все станции открыты; контракты платят на 20% больше | ящик остаётся; `K` отвечает `ГРУЗ ПРИВЯЗАН К ДЕРЖАТЕЛЮ`; в журнале 18 обязательств вместо одного |
| `chaos` | разброс цен между станциями ×2, пиратов на 50% больше, арбитраж выгоднее | `K` срабатывает, ящик пропадает, температура кабины возвращается к норме |
| `council` | цены стабильны (±10%), скидка 5% на всех станциях, контрактов поровну | ящик переходит в общий сейф, `K` срабатывает, но выбрасывать нечего |

Тексты: `e_comb`, `e_chaos`, `e_council` + эпилог.

## 7. Порядок работ

1. **Экран `TALK` и узлы.** Перенос по словам, прокрутка, индикатор `N/M`. Проверить на одной тестовой сцене, что текст читается и влезает в 320×224. *Критерий:* реплика из 30 строк прокручивается, варианты закреплены.
2. **Состояние.** `Flags`, `Papers`, `Boxes`, `Audit`, `Ending`, `ViperClk` в сейве, обратная совместимость. *Критерий:* старый сейв грузится, новые поля нулевые.
3. **Предмет «ЯЩИК».** Правила из раздела 3. *Критерий:* нельзя продать, нельзя сбросить, греет кабину; `K` отвечает.
4. **Глава 1 целиком.** Это прототип всего подхода. Если глава не работает, дальше идти нет смысла. *Критерий:* три ветки, 1 200 во всех, `Boxes` и `Papers` обновляются.
5. **Главы 2–8 по одной**, после каждой — прогон бота по всем веткам.
6. **Финалы и мир.** Модификаторы цен, закрытые станции, концовки.
7. **Перевод.** Одновременно с текстом: сразу `ru.go` и английский.

## 8. Тесты и приёмка

- **Целостность графа:** все `Next` ведут в существующие узлы; нет недостижимых узлов (достижимость проверяется перебором наборов меток); нет узлов без выхода.
- **Ширина:** каждая реплика после переноса укладывается в 46 знаков на строку и 30 строк на узел.
- **Строки:** у каждого ключа есть русский и английский текст; нет строк без ключа.
- **Бот:** четыре стратегии должны пройти кампанию до концовки без невозможных состояний.
  - *жадный:* берёт ящик, платит допуск, бьёт всё, подбирает всё ковшом → `combine`;
  - *чистый:* отказывается от ящика, дерётся, ничего не подбирает → `chaos`;
  - *читатель:* берёт расписку, спрашивает про ящик, копирует самописец, просит аудитора → `council` мирно;
  - *беглец:* уходит в прыжок везде → кампания завершается, поручитель в беде.
- **`TestCampaignChain`:** расширить: проходит восемь глав в каждой из четырёх стратегий, девятый этап не предлагается, `Ending` непустой.
- **Контракты и верфь:** после главы 1 с ящиком доска найма и верфь работают; смена корабля сохраняет `Boxes`.

## 9. Допущения и вопросы к автору

1. **Население на экране системы.** Если его в игре нет, глава 3 обходится совпадением цифр 40 000 в манифесте и в НОМИНАЛЕ. Если есть — использовать.
2. **Щиты станции (глава 7).** В движке их, возможно, нет. Запасной вариант: матка питается от ретранслятора — отдельная цель рядом со станцией; «выключить щиты» заменяется «уничтожить ретранслятор». Нравственная дилемма (двести человек и пираты) при этом сохраняется.
3. **SWARM.** В главе 7 Улей говорит одну строку про «чужой счётчик». Это намёк на SWARM из README: гудение ящика — их техника, купленная конторой как «арифметика, которая не лжёт». Если это не нужно, строка вырезается без последствий для сюжета.
4. **Названия кораблей.** В текстах стоят «Крайт», «Питон», «Боа», «Асп», «Вайпер», «Анаконда» из `campaignQuests`. Если эти имена совпадают с названиями из Elite — заменить на собственные при переводе в ru/en, смысл не меняется.
5. **SHRIKE.** В README прототип назван, но в сценарии он не используется. Если он нужен — первое естественное место: корабль курьера или «Анаконда» Директора.
6. **Порог в 5 бумаг.** Подобран по прикидке: минимальный путь даёт 2–3 бумаги, обычный — 5–7, жадный — 8–10. После первого прохождения ботом проверить распределение и сдвинуть порог.
7. **Время.** Прыжки считаются реальным временем игры, «сутки» — игровым. Если в движке есть только прыжки, `ЖДАТЬ ДО УТРА` = −2 прыжка таймера.
