# Сценарий v2: что взять у Шекли, Азимова и компании

Черновик. Ничего из этого ещё не в игре.

## Что берём у кого

| автор | приём | почему ложится на движок |
|---|---|---|
| Роберт Шекли | обмен, в котором мелкий шрифт важнее цены: помощь, которая ловушка; товар, который не товар | у нас есть доставка, трюм и станция: хватает одного диалога, чтобы «обычный рейс» стал историей |
| Айзек Азимов («Большое и малое», Хобер Мэллоу) | торговец побеждает не оружием, а знанием правил и ценой | рынок, уровни технологий и правительства уже считаются в `galaxy` — это готовая дуэль без выстрелов |
| Фредрик Браун | короткая история с переворотом в последней строке | финальная глава и любой контракт: одна строка меняет смысл всего задания |
| Дэймон Найт («Служить человеку») | каталог, который оказывается меню | контейнер, манифест, «Улей»: то, что мы уже написали как груз |
| Станислав Лем («Звёздные дневники») | бюрократ-абсурд в космосе, инструкция сильнее физики | голос конторы в брифингах уже звучит именно так |
| Азимов, «Три закона» | исполнитель, который понимает инструкцию буквально | финальный босс и станционный ИИ: можно решить не бой, а формулировку |

Общее: **каждая глава — сделка с ловушкой.** Ловушка видна в диалоге сразу, а
её смысл — через две главы. Это то, чего у нас сейчас нет: брифинги дают задачу,
а не сделку.

## Пять правил, по которым пишем

1. В каждой главе есть **выбор**, а не только цель. Минимум два исхода, оба
   платят.
2. Выбор проверяется **механикой**, а не флагом в скрипте: цена, трюм, топливо,
   уровень технологии, репутация.
3. Никто не объясняет мораль. Контора говорит ровно; читать между строк —
   работа игрока.
4. Текст короткий: 4 строки на реплику, 3 варианта ответа. Больше не влезает в
   320×224 и не нужно.
5. Перевёртыш — в конце, одной строкой. Если его можно предсказать с первого
   экрана, глава слабая.

### Глава 1. Медицинский рейс

Диспетчер клиники — женщина в выгоревшем комбинезоне, три реплики, один выбор.

> — ЧЕТЫРЕ ТОННЫ, КАК ЗАКАЗЫВАЛИ.
> — ДЕНЕГ НЕТ. ЕСТЬ ЯЩИК. В ЗАЧЁТ.
> — ВОЗЬМИ. ОН ТЕБЕ ПРИГОДИТСЯ.

Варианты: взять ящик (трюм −2 т, дальше он «гудит»), отказаться (деньги
придут через две недели, +розыск за срыв), потребовать расписку (половина
денег, но бумага пригодится в главе 6).

### Глава 2. Засада

Те же три «Крайта», но в диалоге до боя:

> — ТЫ ПРИВЁЗ ЕДУ. МЫ ЗАБЕРЁМ.
> — ЗАПЛАТИ НАМ — И УЙДЁШЬ.
> — ТРИ ТЫСЯЧИ. ЭТО ДЕШЕВЛЕ, ЧЕМ КОРПУС.

Три исхода: выкупиться (−3 000, репутация у местных +), драться (репутация
правительства −, трофеи), уйти в прыжок (−топливо, глава идёт дальше, но без
награды).

### Глава 3. Чёрный ящик

Манифест найденного «Питона»: три колонки — «ПОСТАВКА», «ПОРЦИИ»,
«ВКУС». Пилот впервые понимает, что читает меню.

### Глава 4. Курьер

Курьер выходит на связь сам: его рейс транслируют. Ставки на то, дойдёт ли он.
Убить — получить 5 200 и попасть в эфир; продать данные — взять 7 000 у
заказчика; отпустить — получить союзника в главе 8.

### Глава 5. Караван

Три «Боа» везут один и тот же товар. Разбить — цена на него в системе падает
вдвое на сутки. Купить у паникующих — цена взлетает. Считать надо до выстрела.

### Глава 6. Подстава

Конторе нужен виновный по бумагам, поэтому виноватым назначен пилот. Чтобы
снять обвинение, нужна таможенная запись с трёх станций: три диалога, три
архива, один чиновник, который берёт взятку и один, который боится.

### Глава 7. Улей

Материнский корабль — не боевой. Это система, которая «обеспечивает
безопасность», останавливая всё движение. Убить её можно только изнутри зоны,
а щиты станции при этом надо выключить: пираты успеют.

### Глава 8. Флагман

«Анаконда» не стреляет первой. Она предлагает:

> — ТЫ УБИЛ МОИХ. ЭТО РАБОТА.
> — ВОЗЬМИ МОЙ ФЛОТ, МОИ ДОКИ, МОЮ КОНТОРУ.
> — ПРОСТО ДАЙ МНЕ УЙТИ.

Два финала: добить (как сейчас) или принять (титры «новый комбинат», другая
концовка).

## Диалоги на станции: как это устроено

Экран `TALK` в меню станции, если в системе есть контакт.

```
┌────────────────────────────────────┐
│ ДИСПЕТЧЕР КЛИНИКИ            ▼ 3/7 │
│                                    │
│ ЧЕТЫРЕ ТОННЫ, КАК ЗАКАЗЫВАЛИ.      │
│ ДЕНЕГ НЕТ. ЕСТЬ ЯЩИК. В ЗАЧЁТ.     │
│ ВОЗЬМИ. ОН ТЕБЕ ПРИГОДИТСЯ.        │
│                                    │
│ МЫ НЕ ПЕРВЫЕ, КТО СПРАШИВАЕТ.      │
│ …                                  │
│                                    │
│ > ВЗЯТЬ ЯЩИК                       │
│   ОТКАЗАТЬСЯ                       │
│   ПОТРЕБОВАТЬ РАСПИСКУ             │
└────────────────────────────────────┘
```

Окно текста — 6 видимых строк по 46 знаков (шрифт 5×7, шаг 6 px). Текст длиннее
**прокручивается**: `↑`/`↓` по строке, `PgUp`/`PgDn` по странице, справа
индикатор `3/7`. Варианты ответа закреплены внизу и не уезжают.

Значит реплика не обязана быть короткой. Узлу разрешено до **30 строк** — это
примерно 1 300 знаков, целый абзац. Больше не нужно: если спикер говорит
дольше минуты, игрок начинает прокручивать не читая.

Длина по типам узлов:

| узел | строк |
|---|---|
| реплика в разговоре | 2–5 |
| вступление к главе, голос конторы | 5–10 |
| записка, манифест, объявление на доске | 8–15 |
| «нашёл в архиве» — кусок документа | до 30 |

Данные — обычная таблица узлов, текстом, без скриптового языка:

```go
type Node struct {
    Speaker string
    Lines   []string // длинные абзацы, перенос по словам делает движок
    Options []Option
}

type Option struct {
    Text  string // что видно игроку
    Next  string // следующий узел, "" — конец
    Cash  int    // +/− кредиты
    Cargo string // товар или предмет в трюм
    Flag  string // метка в сейв
    Spawn string // кого выпустить, если доигрались
}
```

Метки хранятся в сейве (`Cmd.Flags map[string]bool`) и читаются кампанией:
глава 6 смотрит, взял ли игрок расписку в главе 1; глава 8 — отпустил ли он
курьера.

Текст — те же строки, что и всё остальное: ключ латиницей, перевод в
`go/lang/ru.go`. То есть каждая реплика — две строки в двух файлах.

### Пример длинной сцены

Так это выглядит в тексте (глава 1, второй заход):

> — ЧЕТЫРЕ ТОННЫ, КАК ЗАКАЗЫВАЛИ. ВСЁ НА МЕСТЕ, Я ПРОВЕРИЛА.
>
> — ДЕНЕГ НЕТ. НЕ ПОТОМУ ЧТО НЕ ХОТИМ, А ПОТОМУ ЧТО ПОСЛЕДНЮЮ ПЛАТЁЖКУ
> ОТОЗВАЛ КОМБИНАТ. НАМ НЕ ОТКРЫВАЮТ СЧЕТА С АПРЕЛЯ.
>
> — ЕСТЬ ЯЩИК. ОН ОЦЕНИВАЕТСЯ ВЫШЕ, ЧЕМ ТВОЙ РЕЙС. ВОЗЬМИ ЕГО, ПРОДАЙ НА
> ВОЛЬНОЙ СТАНЦИИ И ЗАБУДЬ ПРО НАС. И НЕ ОТКРЫВАЙ. Я СЕРЬЁЗНО: НЕ ОТКРЫВАЙ.
>
> — И ДА. МЫ ТАКИХ РЕЙСОВ ТРИ ПРИНЯЛИ ЗА МЕСЯЦ. ВСЕ ТРИ ПРИВЕЗЛИ ЯЩИК.

Это 4 абзаца, 12 строк — нормальный размер для узла, где игрок делает выбор, от
которого зависит вся глава.

## Объём

| что | сколько |
|---|---|
| узлов диалога | ~55 (8 глав × 5–7, плюс 4 станционных знакомых) |
| реплик | ~220 |
| строк на язык | ~900 |
| знаков на язык | ~35 000 |

Для сравнения: сейчас в кампании 8 брифингов по 3 строки, ~1 200 знаков. То
есть текста станет примерно в тридцать раз больше — и это нормально: прокрутка
позволяет писать абзацами, а не телеграммами.

## Что нужно в движке

| задача | зачем | размер |
|---|---|---|
| перенос по словам и прокрутка | чтобы абзацы влезали | полдня |
| экран диалога + узлы | вся затея | 1–2 дня |
| метки в сейве и эффекты (деньги, трюм, спавн) | выборы должны значить | полдня |
| контакты на станции, привязанные к главе | чтобы диалог появлялся вовремя | полдня |
| меню станции: пункт `TALK` | вход | час |
| переписать 8 глав | собственно сценарий | 2–3 дня текста |
| тесты: все узлы достижимы, нет висячих ссылок, строки влезают | чтобы бот прошёл все ветки | полдня |

## Порядок работ

1. **Экран диалога и узлы** — на одной сцене, без сюжета. Проверить, что текст
   читается и влезает в 320×224.
2. **Глава 1 целиком** — диспетчер, ящик, последствия. Это прототип всего
   подхода: если глава не страшная, дальше идти незачем.
3. **Остальные семь** — по одной, с прогоном бота по обеим веткам.
4. **Перевод** — вместе с текстом, иначе получится снова английский справочник.

## Осторожно

Мы берём приёмы и темы, а не тексты: ни одной чужой фразы, ни одного имени.
Все персонажи, названия и реплики — свои. Это принципиально и по авторскому
праву, и потому что игра и так переименовала всё, что было взято из Elite.
