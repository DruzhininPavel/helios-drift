# ELITE 16 — Go

Клон Elite (1984) с 16-битной графикой: своя палитра, дизеринг Байера,
программный растеризатор полигонов с Z-буфером. Внутреннее разрешение
320×224, апскейл целым коэффициентом.

## Сборка и запуск

```bash
cd ~/Documents/Games/Elite/go
go build -o elite16 .
./elite16
```

Без окна:

```bash
./elite16 -sim      # прогон симуляции: докинг, гиперпрыжок, бой
./elite16 -shots    # рендер эталонных экранов в build/*.png
```

## Управление

| В полёте | |
|---|---|
| Стрелки / WASD / мышь | тангаж и крен |
| Space / ЛКМ | лазеры |
| X / Z | ускорение / торможение |
| M | ракета по цели в прицеле |
| E | E.C.M. |
| Tab | энергобомба |
| L | стыковочный компьютер (если куплен) |
| J | прыжок внутри системы (0.1 LY) |
| C | карта галактики, H — прыжок |
| V | статус командира |
| Esc | пауза / справка |
| Shift+M | выключить / включить звук |

В доке: `1` рынок, `2` оборудование, `3` карта, `4` статус, `5` старт,
`6` сохранить командира, `F` заправка. В рынке `B`/`S` — купить/продать 1 т,
`Shift+B`/`Shift+S` — 10 т.

## Что перенесено из JS-версии

Всё: полёт без рыскания, вращающаяся станция Кориолиса со щелью и стыковкой
по совпадению вращения, 17 товаров с экономикой систем, 8 галактик по 256
систем (с гарантированной связностью в пределах 7 LY), бой с лазерами,
ракетами, E.C.M. и энергобомбой, ИИ пиратов/полиции/торговцев, правовой
статус, ранги, оборудование по техуровням, заправка, топливный скoup,
спасательная капсула, гиперпрыжок с шансом ми­сджампа и таргоидами,
процедурные планеты, туманность, звёзды, HUD и экраны станции.

## Структура

```
main.go             окно ebiten, ввод, режимы -sim и -shots

models/models.go    меши кораблей, станция, астероиды, контейнеры

game/update.go      игровой цикл, ИИ, торговля, заправка
ui/ui.go            HUD, скан, 3D-вид, кокпит, титул, гиперпрыжок
ui/screens.go       экраны станции, обработка клавиш
```

## Отличия от Elite (осознанные)

- Стыковочный компьютер «берёт управление» и заводит в щель за 6 секунд
  (в оригинале он тоже полностью автоматический).
- Прыжок внутри системы (J) — из поздних версий, экономит время перелёта.
- Нет миссий (Constrictor, документы таргоидов) и торговли с кораблями.

## Сохранение

`6` в доке (или пункт меню) пишет командира в `~/.elite16-save.json`,
`2` на титульном экране загружает его и ставит в док последней системы.

## Звук

Все эффекты синтезируются в рантайме (без файлов): квадратные/пилообразные
свипы и фильтрованный шум, 44.1 кГц, 16 бит, стерео.

- лазер, попадание, взрыв, пуск ракеты, E.C.M., энергобомба, стыковка,
  гиперпрыжок, предупреждение о ракете;
- фон двигателя — зацикленная «комната» с громкостью от скорости;
- `Shift+M` — выключить/включить звук.

Проверка синтеза: `go test ./sfx` (длительность, пик, RMS, отсутствие клиппинга
и щелчка на стыке петли).
