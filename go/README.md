# Helios Drift — исходники

Go + Ebiten. Внутреннее разрешение 320×224, апскейл целым коэффициентом;
палитра, дизеринг и растеризатор полигонов свои.

## Сборка и запуск

```bash
go build -o heliosdrift .
./heliosdrift
```

На macOS игру надо запускать из бандла `HeliosDrift.app` (его собирает
`../build.sh`): голый Mach-O не может открыть окно.

Без окна:

```bash
./heliosdrift -sim       # прогон: стыковка, гиперпрыжок, бой, сохранение
./heliosdrift -shots     # эталонные экраны в build/*.png
./heliosdrift -version   # версия, вшитая при сборке
./heliosdrift -bot -mode advanced -seed 7 -frames 36000   # бот-игрок
```

Бот описан в [../docs/bot-testing.md](../docs/bot-testing.md).

## Тесты

```bash
go test ./...
go test ./game -run TestCampaign -v    # сюжет целиком
go test ./bot                          # воспроизводимость, инварианты, стыковка
```

## Структура

```
main.go             окно, ввод, геймпад, флаги (-sim, -shots, -bot, -seed)
render/             палитра, фреймбуфер, растеризатор, шрифт 5×7 и кириллица
models/             меши кораблей и станций, спрайты планет, контейнеры
galaxy/             генерация галактик, рынки, оборудование, ранги
game/               состояние, полёт, бой, стыковка, торговля, сюжет, сохранения
game/rng.go         генератор мира: один сид — один мир
game/hash.go        отпечаток состояния для проверки воспроизводимости
bot/                бот-игрок: политика, пилот, инварианты, запись и реплей
ui/                 HUD, экраны станции, титул, настройки, карта
lang/               русский интерфейс, подменяется на уровне рендера
sfx/                синтез звука в рантайме, без файлов
input/              привязки клавиш и геймпада
```

## Звук

Все эффекты синтезируются при старте: лазер, попадание, взрыв, ракета,
E.C.M., бомба, стыковка, гиперпрыжок, фон двигателя. Проверка синтеза —
`go test ./sfx` (длительность, пик, RMS, клиппинг, щелчок на стыке петли).
